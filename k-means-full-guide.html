Unsupervised learning / clustering

K-Means

Finding groups nobody has labelled.

K-Means takes rows of numbers, a chosen number of groups K, and puts each row in the group whose centre is nearest. This guide uses one small customer table from start to finish: first as a picture, then as a calculation, then as Python code. By the end you should be able to explain what K-Means does, run it, judge whether its groups are any good, and recognise when to use something else. Start at the clustering overview; compare this centre-based method with the DBSCAN full guide.

01Rows with
no labels

A table with no answer column

In supervised learning each row arrives with a known answer, such as a house price or "spam / not spam", and the model learns to predict it. Clustering starts without that column. We have measurements for each row and one question: which rows are similar to each other?

0

group labels supplied

What K-Means will add: a group number for every row. The number is a name tag (0, 1, 2), not an explanation. Working out what each group means is still our job, and Section 11 shows how.

Typical uses real work

  • Customer segmentation: group shoppers by spend, frequency and recency so marketing can treat them differently.
  • Colour reduction: group the pixels of a photo into K colours to compress it (scikit-learn example).
  • Grouping documents or sensors whose measurements look alike, as a first look before deeper analysis.

What it is not common confusion

  • It is not classification. There is no "right answer" column to check against.
  • It does not discover how many groups exist. You choose K.
  • It does not explain why rows are similar. It only measures how close their numbers are.
02Rows
become
points

Each row becomes a point

Pick two numeric columns and use them as axes. Every customer becomes one dot: across for spend, up for visits. Now "similar" has a picture: dots that sit close together.

Feature space is the space made by the columns we choose. Two columns give a flat chart; ten columns give a 10-dimensional space that we cannot draw, but the arithmetic works the same way.Choose columns carefully. A different choice of columns gives a different picture and different groups.
03Distance
and
scale

"Near" means a measured distance

K-Means measures closeness with ordinary straight-line (Euclidean) distance: the length of a ruler laid between two points. Before measuring, we usually put every column on a comparable scale, and this section shows why that matters so much.

Step 1: put the columns on the same scale

Spend runs into hundreds of pounds; visits run into tens. Standardising turns each value into "how many standard deviations above or below the column average". A standard deviation measures how spread out a column is: roughly, the typical distance of a value from the column's average. So a scaled value of +1 means "one typical step above average", whatever the original units were. This is what scikit-learn's StandardScaler does.

scaled value = (value − column mean) ÷ column standard deviation
spend: mean £587, standard deviation £349  ·  visits: mean 26.4, standard deviation 23.1

Step 2: measure a distance

Take customers A and D. Subtract their scaled values column by column, square the gaps, add them, and take the square root. This is Pythagoras' theorem.

A = (-1.39, -0.71)    D = (0.04, 1.23)
gaps: 1.43 across, 1.95 up
distance = √(1.43² + 1.95²) = 2.41

Why scaling changes the answer

A second small example (customers P–W) shows what goes wrong without scaling. Four customers visit about 4 times a year and four visit about 34 times. Their spending is spread widely in both sets.

Raw units groups: PQTU / RSVW

In raw units a £1 difference counts the same as one visit. A 30-visit gap is worth only £30, so K-Means splits the customers by spend and ignores visits almost completely.

Standardised groups: PQRS / TUVW

After standardising, both columns have a fair say. K-Means now separates the rare visitors (P–S) from the frequent ones (T–W).

Scaling is a decision, not a ritual. Standardising says "treat one standard deviation of each column as equally important". Usually that is what you want. Sometimes the raw units carry real meaning and you may choose not to scale, or to weight a column. Either way, state which version K-Means received. Scaling is also sensitive to outliers, because one extreme value stretches the standard deviation (scikit-learn preprocessing guide).
04The loop,
step by
step

Assign, move, repeat

K-Means does not look at the chart and "see" groups. It runs a short loop, usually called Lloyd's algorithm: place K centres, give each row to its nearest centre, move each centre to the average of its rows, and repeat until nothing changes (scikit-learn clustering guide).

Choose K

How many groups to look for. You supply this number.

02

Place K centres. Here they start on real rows; scikit-learn uses a smarter spread (Section 07).

03

Assign

Each row joins the centre it is closest to.

04

Update

Each centre moves to the mean position of the rows that joined it.

05

Repeat

Go back to Assign. Stop when no row changes group.

Inspect

05What it
minimises

One number measures how tight the groups are

Draw a line from every row to its own group centre. Square each line's length and add them all up. That total is called inertia, or the within-cluster sum of squares (WCSS). K-Means is trying to make this number as small as possible (scikit-learn KMeans reference).

Why the centre is the mean

The Update step moves each centre to the average of its rows. That is not an arbitrary choice: for a sum of squared distances, the average is the single position that gives the smallest total. Take the spend of A, B and C (£100, £150, £200) and try every possible centre:

What the maths guarantees, and what it does not. Each step lowers or keeps inertia, so the loop always settles. But it settles on the best answer reachable from where it started, which may not be the best answer overall. Finding the true best grouping is a very hard problem in general, which is why the starting positions in Section 07 matter.

The elbow method

Inertia always falls as K rises: with more centres every row can sit closer to one. At K = 9 every row would have its own centre and inertia would be zero. So "lowest inertia" is useless on its own. Instead, look for the point where adding another group stops buying much improvement: the elbow.

Elbow chart inertia vs K

From K=2 to K=3 inertia drops from 8.698 to 0.190. After that the line is almost flat. The elbow is at 3.

Silhouette chart mean score vs K

The mean silhouette score (explained below) is highest at K=3, agreeing with the elbow.

Real data is rarely this tidy. Often the elbow curve bends gently with no clear corner, and the two charts may disagree. scikit-learn's own silhouette example ends up with more than one reasonable K. When that happens, choose using what the groups will be used for.

The silhouette value, built up from one customer

Each row gets its own silhouette value between −1 and +1. It compares two averages (Rousseeuw, 1987):

a = average distance from the row to the other rows in its own group  (small is good)
b = average distance from the row to the rows in the nearest other group  (large is good)
silhouette = (b − a) ÷ the larger of a and b

Take the K = 2 result, where the groups are ABC / DEFGHI. Customer D shares its group with E and F, but also with G, H and I, which sit far away:

near +1  → the row is much closer to its own group than to any other
near 0   → the row sits on a boundary between two groups
below 0  → the row is closer to another group than to its own: probably misplaced

Plot every row's value as a bar, grouped by cluster, and you get a silhouette chart. Compare K = 2 with K = 3:

K = 2 mean 0.55

The D–I group has short bars: its members are loosely held. Short or negative bars point at a group that is really two groups, or at rows that sit between groups.

K = 3 mean 0.90

Every bar is long and every group looks similar. This is what a clear, well-separated grouping looks like.

Read the bars, not only the mean. One average can hide a group of poorly placed rows. In Python, silhouette_score gives the mean and silhouette_samples gives the value for every row (scikit-learn reference).
07Starting
positions

Where the centres start changes where they finish

Because the loop only ever goes downhill, a bad start can trap it. In the stepper in Section 04, starting on A, C, G puts two centres inside the A–C clump and only one centre for everything else.

Fix 1: start the centres far apart (k-means++)

k-means++ chooses the first centre at random, then picks each further centre with a probability proportional to its squared distance from the nearest centre already chosen (Arthur & Vassilvitskii, 2007). Rows far away become likely picks; rows close by become unlikely. Suppose A is chosen first:

Fix 2: run it several times and keep the best

Run K-Means from several different starts and keep the run with the lowest inertia. In scikit-learn this is the n_init setting. The default is init="k-means++" with n_init="auto", which currently means one run when k-means++ is used (KMeans reference). On messy real data it is worth asking for more, for example n_init=10.

Also set random_state to a fixed number. Then you, and anyone checking your work, get the same groups every time the notebook runs.
08Where it
goes
wrong

Four ways K-Means can mislead you

K-Means has a built-in picture of what a group is: a compact, roughly round blob around one centre, with every row forced into exactly one group. When the data does not look like that, it still returns an answer, and the answer can look perfectly tidy (scikit-learn: demonstration of K-Means assumptions).

1. No real groups noise

These 90 points are pure random scatter. K-Means still carves them into three neat regions, because it always returns K groups. The mean silhouette is 0.42, which is not a warning-level number on its own. Always ask whether groups exist before trusting any.

2. Rings and curves shape

The obvious answer is "inner ring" and "outer ring". K-Means cannot give it, because the boundary between two centres is always a straight line. Density-based methods such as DBSCAN handle shapes like this.

3. Long, thin groups stretch

Two long bands of points. A single centre in the middle of a long band is far from its ends, so here K-Means cuts across the bands instead of separating them. Gaussian mixture models allow stretched, oval groups.

4. One extreme row outlier

Add customer J, who spends £3,200. With K=3 the groups become ABCGHI / DEF / J: J takes a whole group for itself, so two genuine groups are merged. Check for outliers before clustering and decide how to treat them.

A fifth problem you cannot draw: many columns. As the number of columns grows, the distances between all pairs of rows become more and more alike, so "nearest" means less. Google's clustering course calls this the curse of dimensionality and suggests reducing dimensions first, for example with PCA (Google, K-Means advantages and disadvantages).
09When to
use it

When K-Means is the right tool

Sections 03–08 give you everything needed to decide. This section puts it in one place.

Good fit reach for K-Means

  • The columns are numeric and averaging them makes sense (spend, counts, measurements).
  • You expect groups that are compact and roughly similar in spread.
  • You want a fast first look, or you have a lot of rows. For very large data, scikit-learn's MiniBatchKMeans trades a little accuracy for much more speed.
  • You have a sensible idea of K, or a range of K to compare.
  • You need to place new rows into existing groups later: just find the nearest centre.

Poor fit consider something else

  • Columns are categories such as colour or region. The average of "red" and "blue" means nothing. Use a method built for categorical data.
  • Groups are likely to be curved, ringed or stretched (Section 08).
  • You expect noise and outliers that should belong to no group.
  • Groups have very different spreads or densities.
  • You need a probability of membership rather than one hard label.

10K-Means
in Python

The whole route in pandas and scikit-learn

Everything you have seen so far, in four short blocks, using the same nine customers. Each block does one job from the loop diagram: prepare, compare K, fit, use.

Reading the code. Lines starting with # are comments: notes for people, which Python ignores. Every line below has one. Words in highlighted code are explained in the notes beside each block, and all new terms are in the glossary at the end.

Block 1: prepare and scale

# pandas: the library for tables of data
import pandas as pd
# StandardScaler: puts columns on comparable scales
from sklearn.preprocessing import StandardScaler
# KMeans: the clustering method
from sklearn.cluster import KMeans
# silhouette_score: marks how well-separated the groups are
from sklearn.metrics import silhouette_score

# build the table from Section 01 (a DataFrame)
customers = pd.DataFrame({
    "customer": list("ABCDEFGHI"),   # the letters A to I
    "spend":  [100, 150, 200, 600, 650, 580, 1000, 1050, 950],
    "visits": [10, 12, 8, 55, 60, 62, 10, 13, 8],
})

# keep only the columns to cluster on (not the letter)
features = customers[["spend", "visits"]]

# fit_transform: learn each column's average and spread,
# then return the scaled numbers from Section 03
scaler = StandardScaler()
X = scaler.fit_transform(features)

Read down the code

  1. Import three specific tools: one prepares data, one clusters, one scores.
  2. Build the same table as Section 01.
  3. Select only the numeric columns to cluster on. The customer letter is a label, not a feature.
  4. Scale: fit_transform learns each column's mean and standard deviation, then returns the scaled table from Section 03.

Block 2: compare several K

# try K = 2, 3, 4, 5, 6 (range stops before 7)
for k in range(2, 7):
    # n_init=10: run from 10 different starts, keep the best
    # random_state=42: any fixed number, so results repeat
    # fit = run K-Means on the scaled data
    model = KMeans(n_clusters=k, n_init=10,
                   random_state=42).fit(X)
    # labels_ = the group number for each row
    score = silhouette_score(X, model.labels_)
    # inertia_ = squared distances to centres (Section 05)
    print(k, round(model.inertia_, 3), round(score, 3))

Read down the code

  1. Loop over candidate values of K.
  2. Fit K-Means with ten starts and a fixed seed (Section 07).
  3. Score the grouping with the mean silhouette.
  4. Print K, inertia and silhouette. Plot these to get the two charts from Section 06.

Block 3: fit the chosen K and describe the groups

# fit the final model with the chosen K = 3
model = KMeans(n_clusters=3, n_init=10,
               random_state=42).fit(X)
# add each row's group number as a new column
customers["cluster"] = model.labels_

# groupby: split the table by group number;
# agg: work out one summary per group
profile = customers.groupby("cluster").agg(
    spend=("spend", "mean"),       # average spend
    visits=("visits", "mean"),     # average visits
    size=("customer", "count"),    # how many customers
)
print(profile)

Read down the code

  1. Fit the final model with K = 3.
  2. Attach each row's group number to the original table. labels_ is in the same row order as X.
  3. Profile: average each column per group, in the original units, and count the rows.

Block 4: place a new customer

# one new customer, with the same two columns
new = pd.DataFrame({"spend": [700], "visits": [45]})
# transform (not fit_transform): scale with the SAME averages
# and spreads learned from the original nine customers
new_scaled = scaler.transform(new)
# predict: the number of the nearest centre
print(model.predict(new_scaled))

Read down the code

  1. Describe the new customer with the same two columns.
  2. Scale with the already fitted scaler: transform, not fit_transform, so the new row uses the original means and standard deviations.
  3. Predict: return the number of the nearest centre. No refitting happens.

11Describe
the
groups

A group number is not a meaning

K-Means stops at "customers A, B and C are group 0". Turning that into something useful is analysis work: describe each group in the original units, name it cautiously, and check it is stable before anyone acts on it.

GroupCustomersMean spendMean visitsA possible description
0ABC£15010.0low spend, few visits
1DEF£61059.0mid spend, frequent visits
2GHI£1,00010.3high spend, few visits

The group centres, converted back to original units: £150 and 10.0 visits; £610 and 59.0 visits; £1,000 and 10.3 visits. These are the same numbers as the profile, because each centre is the mean of its members.

Good practice describing groups

  • Report the group sizes. A group of one row is usually an outlier, not a segment.
  • Describe groups by the columns that differ most between them.
  • Use cautious names ("frequent, mid-spend") rather than claims ("loyal customers").
  • Refit with a different random_state or on a sample. If the groups change a lot, say so.

Seeing many columns PCA

  • With more than two columns you cannot draw the feature space directly. PCA can squash it to two dimensions for a picture (scikit-learn PCA guide).
  • PCA re-expresses the columns; it does not create groups. Clustering on all columns and clustering on two PCA components are different analyses. Say which one you did.
  • A 2-D picture of 10-D groups can make them look more mixed than they are.
Groups describe, they do not explain. Finding that frequent visitors spend a mid-range amount does not show that visiting causes spending, or the reverse. Clustering is exploratory: it suggests questions for further analysis.
12Other
methods

When the shape is wrong, change the method

Each clustering method has its own idea of what a group looks like. Match the method to the shape you expect. scikit-learn's clustering comparison runs many methods side by side on the same toy shapes; it is the best single picture of these differences, though 2-D toy data does not always predict how a method behaves on real, many-column data.

Compact groups

K-Means

You choose K. Each row joins its nearest centre. Fast, simple, one hard label per row.

Nested groups

Hierarchical

Merges the closest rows step by step into a tree. Cut the tree at any height to get a number of groups (guide).

Dense regions + noise

DBSCAN

Grows groups through crowded areas. Finds curved shapes, needs no K, and labels isolated rows as noise (guide).

Soft, oval groups

Gaussian mixtures

Models each group as a stretched oval and gives each row a probability of belonging to each group (guide).

SituationTry first
Compact numeric groups, a rough idea of K, lots of rowsK-Means (MiniBatchKMeans if very large)
Curved or irregular shapes; outliers that should belong nowhereDBSCAN
You want to see how groups nest inside bigger groupsHierarchical (agglomerative)
Stretched, overlapping groups; you want membership probabilitiesGaussian mixture model
13Check
yourself

Can you explain it without looking?

Answer each question in your head before opening it. The later questions need you to combine ideas from several sections.

1. What is missing from a clustering table, compared with supervised learning?

The answer (target) column. There are features but no known group for any row.

2. What does the Assign step change, and what does the Update step change?

Assign changes which group each row belongs to. Update changes where each centre sits: it moves to the mean of its current members.

3. Why does the Update step use the mean?

For a total of squared distances, the mean is the position that makes the total smallest (the bottom of the curve in Section 05).

4. Why not just pick the K with the lowest inertia?

Inertia always falls as K rises and reaches zero when every row has its own centre. Look for the elbow and check silhouette values instead.

5. A row has a silhouette value of −0.2. What does that suggest?

On average it is closer to the rows of another group than to its own group. It is probably in the wrong group, or sits between groups.

6. Two runs on the same data give different groups. Why, and what do you do?

Different starting centres can settle in different places (Section 07). Use k-means++, several starts (n_init), and a fixed random_state; keep the lowest-inertia result.

7. Why scale spend and visits before clustering?

Without scaling, the column with the biggest numbers dominates the distance. In the P–W example, raw pounds made K-Means ignore visits completely.

8. Your data forms two rings. Will K-Means find them?

No. Its boundaries between centres are straight lines, so it cuts both rings in half. Try DBSCAN.

Transfer challenge. A colleague clusters shop customers on income (in pounds) and number of visits, gets five groups, and presents them as "the five true customer types". List what you would check before accepting that.
Open a model answer
  • Were the columns standardised, or did income in pounds swamp visits?
  • Why five? Show the elbow and silhouette evidence, and what the groups are for.
  • Are any groups tiny, suggesting outliers took them?
  • Do the groups stay the same across several starts and on a resample?
  • Is there real structure at all? K-Means returns five groups even for random noise.
  • "True types" overclaims. These are proposed groups to describe and test, not discovered facts.

15Glossary

Words used in this guide

Every technical term used in this guide, in plain English, in alphabetical order.

TermWhat it means
ArrayA grid of numbers, like a table with no column names. scikit-learn models take their input as an array. .to_numpy() turns a pandas table into one.
Centre (centroid)The average position of all the rows in one group. K-Means moves each centre to this average at every Update step.
ClusterA group of rows that the method has decided belong together.
ClusteringFinding groups in data when nobody has said what the groups are. It is a kind of unsupervised learning.
DataFramepandas' name for a table: rows and named columns, like a spreadsheet inside Python.
DistanceHow far apart two rows are. Both guides use straight-line (Euclidean) distance: square the gap in each column, add the squares, take the square root.
Elbow methodPlot inertia for several values of K and look for the point where adding another group stops helping much.
FeatureA column used as input to the method, such as spend or km east. Label columns like a customer letter are not features.
FitRun the method on your data so it can learn from it. .fit(X) is where the actual work happens.
Inertia (WCSS)Add up the squared distance from every row to its own group centre. Smaller means tighter groups. WCSS stands for within-cluster sum of squares.
KThe number of groups you ask K-Means to find. You must choose it.
k-means++A way of choosing starting centres that spreads them out, so the method is less likely to get stuck.
LabelThe group number the method gives each row, stored in labels_. It is a name tag (0, 1, 2 …), not a meaning.
n_initHow many times K-Means runs from different starting centres. The run with the lowest inertia is kept.
pandas / pdThe Python library for working with tables. pd is the usual short name for it.
ParameterA setting you choose before running a method, such as n_clusters, eps or min_samples.
PCAPrincipal component analysis: a way of squashing many columns into fewer for a picture. It does not create groups.
predictGive a new row the number of its nearest centre, using a model that has already been fitted.
random_stateA fixed number that makes the random parts of a method repeat exactly, so you get the same answer every run.
RowOne record in the table: one customer, one pothole report.

Silhouette valueA score from −1 to +1 for each row: near +1 means it sits well inside its group, near 0 means on a boundary, below 0 means probably in the wrong group.
Standard deviationA measure of how spread out a column's values are: roughly, the typical distance of a value from the column's average. Small means values are bunched together; large means they are spread out.
transform / fit_transformfit_transform learns a column's average and spread and scales it in one go. transform scales new data using what was already learned.
Unsupervised learningLearning from data that has no answer column. The method has to find structure by itself.
