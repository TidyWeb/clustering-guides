Clustering

Finding possible groups without supplied labels.

Imagine a table of people, places, or things. We know something about each row, but nobody has given us the group names. Clustering looks for rows that are alike in the features we chose. It offers a pattern to investigate—not a hidden answer it can prove is true. This overview is the shared starting point for three full method guides. Follow this order: DBSCAN explores dense neighbourhoods without choosing K; HDBSCAN follows with groups of different densities; then K-Means explores centre-based groups and the choice of K.

01The
basic
idea

What changes when no answer is supplied?

In a supervised task, examples come with answers such as “late” or “on time”; the model learns to predict those answers. In clustering, we have descriptions of the records, but no supplied category telling us which records belong together. We ask whether the descriptions reveal useful structure.

Supervised learning
features + known answer

Learn a rule that predicts the answer for another case.

Clustering
features, no group answer

Propose which records sit near one another in the chosen representation.

Keep the distinction clear: “Unlabelled” means the group answer was not supplied for this task. It does not mean the rows contain no information.

03Choose
what
counts

“Similar” is a modelling choice.

A computer cannot compare customers by an unspoken idea of “alike”. We choose which measurements represent each row, and those choices define what closeness means. Change the features, their units, or their relative influence, and a row can look close to different neighbours.

04A first
method
map

Different methods look for different kinds of structure.

“Clustering” is a family name, not one single recipe. Start by matching the shape of the question to a method’s basic behaviour. DBSCAN, HDBSCAN and K-Means each have a full guide. Begin with DBSCAN to follow dense neighbourhoods; continue to HDBSCAN when groups have different densities; then compare both with K-Means, which builds groups around a chosen number of centres.

Choose the number of groups

K-Means

You tell it how many groups, K, to make. It works by assigning points to nearby centres and updating those centres. A useful first fit for compact, roughly round groups.

Find connected dense regions

DBSCAN

It grows groups from dense neighbourhoods and can leave sparse points as noise. It does not ask you to choose K, but its density settings matter.

Build a nested merge picture

Hierarchical

It builds a hierarchy of merges or splits. HDBSCAN uses a density-based hierarchy to handle groups with different densities; other hierarchical methods need a linkage choice and a cut level.

Model overlapping distributions

Gaussian mixtures

It models data as a mixture of distributions. Membership can be expressed as probabilities rather than only one hard assignment.

Three guides in sequence: Start with the full DBSCAN guide to follow groups growing from dense neighbourhoods; continue to the full HDBSCAN guide to see how groups with different densities are handled; then read the full K-Means guide to follow its centre-and-assignment loop and see why you must choose K. All three build on this overview and explain different ideas of what a group is.
05Read
the
result

A cluster number is not an explanation.

If a method gives a row “cluster 0”, that number is just a computer-made identifier. It does not mean “valuable customer”, “at risk”, or any other human story. We have to go back to the original features, summarise the groups, check whether they are stable, and ask whether the distinction is useful for a real purpose.
